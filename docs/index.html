Student Grading System

Project structure and local setup notes.

Open the application

Project structure

  • config/db.php contains the MySQL connection.
  • includes/csrf.php provides CSRF token helpers.
  • templates/ contains the shared page header and footer.
  • docs/ contains the stylesheet and JavaScript assets.
  • The root PHP pages provide login and student-result operations.

Run locally

Place the project in your web server directory, configure the database connection in config/db.php, then open index.php through your local PHP server.
